# Adsum

**A chamada por crachá, do primeiro dia de aula até a frequência lançada no SIGAA.**

O aluno encosta o crachá num leitor USB. O nome aparece na tela, a presença fica
gravada numa pasta do computador do professor, e as faltas vão para a planilha
de frequência do SIGAA em três cliques.
